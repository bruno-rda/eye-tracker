# The profile is enrolled in batch outside the pipeline, and every estimator gets the same calibration

The personal part of a calibration profile (head slopes, appearance weights) is fitted by enrolment: a batch step per estimator over whole development sessions, every block's fixation targets revealed. Inside the pipeline an estimator fits only the session part, from one fixed calibration of 10 static fixation targets shown by the presenter. Building the personal part from events in the stream was rejected: it would train an appearance model inside a streaming replay, and the 30 s cannot pay for it (10 static fixations cannot tell eye from head, and a held fixation costs about 6 s against 2.7 s). Letting each estimator choose its fixation targets was rejected: the live presenter would depend on the estimator, and a recorded session could not serve an estimator whose layout it did not record. The cost: first use needs a recorded session, no estimator can ask for a layout that suits it, and head slopes carrying across days is unverified (same day: 0.33 against 0.31 to 0.36 px per degree of yaw).
